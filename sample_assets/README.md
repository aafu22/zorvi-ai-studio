# Sample assets

`sample-product.jpg` is the product photo used by **demo mode** (the "Try the demo" button on the dashboard).
It is generated by `make_sample_product.py`, so it is original to this project and has no third-party licence.

To use a different demo photo, replace `sample-product.jpg`, or point `SAMPLE_ASSETS_DIR` in `backend/.env`
at another folder that contains a file with that name.
